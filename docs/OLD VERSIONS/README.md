# OLD VERSIONS

Este archivo conserva la documentación de referencia de las implementaciones
anteriores de P.R.S.

En el repositorio no existían carpetas físicas `v3.0` y `v4.0`: sus pantallas y
servicios estaban integrados en el código común. Por eso se han creado estas
carpetas de archivo para separar la documentación histórica sin duplicar
clases Kotlin ni modificar el código original compartido.

- `v3.0`: documentación del escáner y sus herramientas originales.
- `v4.0`: documentación del flujo de seguimiento sobre mapa.

La navegación actual se presenta como `SENTRY`, `TRACKER`, `DEVICES` y
`USER GUIDE`.
