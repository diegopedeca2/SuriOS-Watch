\# 1. Objetivo



Este documento resume las funcionalidades disponibles en cada versión publicada del ecosistema SuriOS.



Su finalidad es ofrecer una visión clara de la evolución del producto desde el punto de vista del usuario.



No sustituye:



\- al CHANGELOG;

\- al WFPRD;

\- a los ADR;

\- a los Sprint.



Cada versión deberá describir únicamente el resultado final disponible para el usuario.



\---



\# 2. Normas de uso



Las Release Notes deberán cumplir las siguientes reglas:



\- Cada versión aparecerá una única vez.

\- Solo se incluirán funcionalidades realmente finalizadas.

\- No se documentarán funcionalidades en desarrollo.

\- No se incluirán tareas internas.

\- No se incluirán decisiones arquitectónicas.

\- No se incluirán incidencias pendientes.

\- Cada versión deberá mantenerse inmutable una vez publicada.
