# Previous Versions

Esta carpeta contiene las dos copias de seguridad de la esfera al cerrar cada
Sprint:

- la versión anterior al Sprint;
- la versión final después del Sprint.

Las copias incluyen el código fuente, los recursos y la configuración. No
incluyen carpetas `build`, cachés ni salidas temporales.

## Copias actuales

- `watchface-v1.4-sprint-039/`: versión anterior al Sprint 039.
- `watchface-v1.5-sprint-039-final/`: versión final del Sprint 039.

La carpeta histórica `Previous Version` se conserva para mantener las
referencias de Sprints anteriores.
